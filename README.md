# Cyra Tech Elevate

You are a senior UI/UX designer, frontend architect and creative developer specialized in premium technology company websites.

Build a complete, production-ready responsive website for an African technology and engineering company called:

CYRA TECH

The company combines:

- Software development

- Web and mobile applications

- IoT and connected systems

- Hardware engineering

- Cloud infrastructure

- Technical consulting

The positioning is:

"Technology built for the real world."

Cyra Tech is NOT a gaming company, NOT a generic IT agency and NOT a simple software development freelancer.

The website must communicate:

- Innovation

- Engineering expertise

- Reliability

- African technological ambition

- Professionalism

- Modernity

- Technical precision

- Trust

The visual quality should feel similar to a premium modern technology company website such as a high-end SaaS/engineering company, while maintaining a distinct African technology identity.

- Navbar

- ServiceCard

- ProjectsSection

- ProjectCard

- CTASection

- Footer

- illustration below text

- CTAs stacked or horizontally compact

- technology labels wrap

Expertise cards:

horizontal scroll or single-column layout.

single column.

hamburger menu.
