# Cyra Tech Homepage

## Goal
Build the supplied Cyra Tech homepage as a polished, production-ready responsive website while preserving the reference composition, palette, content, and engineering-focused African identity.

## Build
- Define the electric-blue, violet, sky, magenta, navy, soft-background, border, typography, shadow, and motion tokens.
- Create reusable navigation, brand mark, buttons, headings, expertise cards, project cards, CTA, footer, and custom technology artwork.
- Build the full homepage at `/` with the exact requested section order and wording.
- Use purpose-made project imagery for agriculture, operations software, and industrial IoT.
- Add sticky desktop navigation, an accessible animated mobile menu, keyboard focus states, semantic landmarks, and restrained motion.
- Add the requested title, description, Open Graph metadata, canonical URL, and social metadata.

## Responsive verification
- Check desktop, tablet, and mobile layouts in the live preview.
- Correct overflow, clipping, spacing, menu behavior, image framing, and animation issues.
- Confirm the final preview has no runtime or build errors.

## Technical details
- Use the existing React 19, TanStack Start, TypeScript, Tailwind CSS v4, and Lucide stack; this project does not support Next.js.
- Keep presentation code split into focused reusable components.
- Build the abstract software + hardware + IoT visual as a lightweight custom React/SVG composition rather than a generic illustration.
